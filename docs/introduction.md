# Introduction to AlgoViz

Welcome to the **AlgoViz** documentation. 

AlgoViz is a next-generation, interactive code execution visualizer specifically architected to bridge the gap between abstract algorithms and visual mental models. Whether you are an educator explaining intricate graph algorithms, or a student debugging memory pointers, AlgoViz brings your logic to life line-by-line.

## The Core Philosophy

Unlike standard debuggers that require heavy IDE configurations and complex attach-processes, AlgoViz operates entirely in your browser using an **Agentic Developer's Workbench** aesthetic. The design is explicitly stripped of visual noise—focusing entirely on stark typography, high-contrast layouts, and absolute clarity.

We believe that learning Data Structures and Algorithms requires seeing the *state* of the machine at every exact execution step. 

## Key Capabilities

1. **Instant Transpilation**: Write raw C++ or JavaScript. AlgoViz parses your structural loops, vectors, and recursion natively.
2. **Algorithmic Array Pointers**: AlgoViz doesn't just show an array; it actively hunts your variable scope for algorithmic pointers (like \`i\`, \`j\`, \`mid\`, or \`high\`) and visually tracks them floating above your matrix in real-time.
3. **Execution Sandbox**: Your code runs safely within an infinite-loop-protected Sandbox timeline. You can scrub backwards and forwards through time exactly like a video player.
